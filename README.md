# AX9000 Mihomo 透明代理方案 (純 AI 專用)

本項目提供小米 AX9000 宿主機 Mihomo 透明代理配置，嚴格遵循安全脫敏與高性能分流原則。

## 分流策略
- **電視盒子 (192.168.31.39)**: 強制走代理 (`auto` 代理組)。
- **其他設備**: 全數走 `DIRECT` 直連，無需代理。

## 安全維護
- 所有配置文件均已脫敏。請在 `configs/mihomo_config_template.yaml` 中自行填寫真實節點信息。
- 請勿提交含真實憑證的配置文件。

## 管理技能
請使用 `ax9000-mihomo-management` 技能進行配置維護。
