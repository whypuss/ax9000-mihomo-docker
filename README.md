# AX9000 Mihomo 透明代理方案

## 核心設計
本方案採用「宿主機二進制 Mihomo + iptables 精確劫持」架構，解決了 Docker 環境下 OOM 崩潰問題，並實現了設備級分流。

## 關鍵運作原理
1. **策略組分流 (偷天換日)**：將數百條域名規則指向一個  策略組 (默認 DIRECT)，實現全局直連。
2. **iptables 精確劫持**：僅對電視盒 (192.168.31.182) 進行流量重定向 ()，其餘設備流量直接放行 (ACCEPT)，確保互不干擾。

## 故障排查 (黃金法則)
- **設備異常**：優先檢查  規則順序。
- **規則優先級**： 區塊最上方必須確保無阻塞邏輯。
- **QUIC 攔截**：務必確認 iptables 涵蓋 UDP/443。
